# PETER

> Personal Executive Thinking & Execution Response

Assistente pessoal inteligente desenvolvido em Python.

## Objetivo

O PETER será um assistente pessoal capaz de:

- Reconhecer comandos de voz
- Responder por voz
- Conversar utilizando IA
- Executar comandos no computador
- Abrir e controlar aplicações
- Gerenciar arquivos
- Possuir memória
- Analisar informações
- Interpretar a tela do computador
- Automatizar tarefas
- Possuir uma interface própria
